# Portfolio direction

Audience: Data Analyst / BI and Data Engineer, with equal prominence. The opening has two equal entry paths into one commercial intelligence product. Analysis explains a business decision; engineering proves how the underlying data is produced and maintained.

Reference: `portfolio-concept.png`, generated with the built-in image tool on 2026-11-12. Prompt: editorial bilingual Gabriel Costa portfolio, warm paper (#f6f5f0), pine (#153d32), sage (#dbe6dd), ochre (#b78a45), serif headlines, sans-serif controls, two equal audience paths, commercial workspace, source-to-analysis evidence, CV/contact. The concept is a layout reference. Its invented metrics, email, dates and chart trajectory are deliberately replaced by the repository's actual generated results and existing contact links.

Tokens: background #f6f5f0; ink #153d32; text #233b32; secondary #58665d; border #d4dad1; sage #e6ebe1; gold #a16b28. Self-hosted Instrument Serif headlines and DM Sans body; monospace run IDs. 1240px content, 44px minimum desktop gutters, 20px mobile gutters. 4px controls, 7px analytical surfaces; thin dividers and no decorative shadow system. Hero is open two-column type and real data chart; project is an editorial rail beside a workspace preview; engineering is an open horizontal pipeline; about/contact is a compact closing band. Both hero buttons have the same primary treatment, reflecting the user's explicit equal-audience requirement.

Motion: short hover transitions, chart changes without perpetual animation, native smooth scroll disabled under reduced motion. Charts, labels, and controls are native HTML/SVG. All project numbers come from the immutable published snapshot; nothing is labeled as a live production system.
