Definições e decisões

Receita = quantidade × preço unitário. Lucro bruto = receita − custo direto. Margem = soma do lucro ÷ soma da receita. Valores monetários são armazenados em centavos inteiros no pipeline.

Na base completa, Equipamentos lidera a receita; Serviços contribui mais para o lucro bruto. Uma análise comercial deve comparar os dois indicadores antes de priorizar uma categoria. Como a base é sintética, essa conclusão demonstra o método e não é uma recomendação para uma empresa real.

Não há impostos, devoluções, frete ou descontos. Cada pedido tem uma linha. Os filtros representam meses completos; não há previsão ou inferência causal.
