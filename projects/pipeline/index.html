Execute localmente

git clone https://github.com/GabrielCosta06/portfolio-data-analyst.git
cd portfolio-data-analyst
python src/pipeline.py --generate
python -m unittest discover -s tests -v

Python 3.10+. A execução local gera um warehouse SQLite, arquivos CSV, um manifesto e os dados para o navegador. Divergências no esquema interrompem a execução antes de substituir os resultados anteriores.
