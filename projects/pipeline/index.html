Pipeline de dados

Da origem à análise: ingestão de CSV, validação de contrato, tratamento de duplicidades, quarentena e publicação de uma camada analítica em SQL.

Estudo com dados sintéticos. O pipeline Python/SQLite foi executado e testado localmente. O notebook PySpark/Delta é um complemento para Databricks e ainda não foi executado em um workspace cloud.

Problema e solução

Arquivos de vendas podem conter duplicidades, datas inválidas e valores inconsistentes. Somá-los diretamente distorce indicadores. O pipeline valida cada linha antes de disponibilizá-la para análise e preserva a justificativa das rejeições.

CSV sintético → contrato de esquema → validação e deduplicação

Como reproduzir

git clone https://github.com/GabrielCosta06/portfolio-data-analyst.git
cd portfolio-data-analyst
python src/pipeline.py --generate
python -m unittest discover -s tests -v
python -m http.server 8080

Abra http://localhost:8080. Python 3.10+; nenhuma dependência externa para o pipeline local. Cada execução substitui a camada analítica de demonstração, sem acumular pedidos.

Decisões técnicas

  • Grão: uma linha por pedido. Duplicidades válidas preservam a primeira ocorrência; conflitos precisam de uma regra de atualização em um cenário real.
  • Valores financeiros calculados com Decimal e armazenados em centavos inteiros.
  • Mudanças nas colunas de entrada interrompem a execução antes de substituir o último resultado.
  • Manifesto registra o hash SHA-256 da entrada, contagens, falhas e agregações para conciliação.
  • Exportações derivam dos mesmos registros aceitos. Não há conexão com sistemas ou dados de um empregador.

Limites e evolução

O processamento é batch e em memória. Não implementa CDC, streaming, retries de rede, scheduler, autenticação ou recuperação transacional entre todos os arquivos de saída. Para produção, esses requisitos precisam de projeto e validação próprios.

O complemento Databricks usa CSV como Bronze, validação e deduplicação como Silver e agregação mensal como Gold. AWS e Azure são caminhos de aprendizado e não foram provisionados neste estudo.
