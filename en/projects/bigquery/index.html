Sales with Google BigQuery

How did revenue and margin change over six months? This study uses GoogleSQL and the dataset validated by the lakehouse pipeline.

Download GoogleSQL query Run guide

Synthetic data. I checked the expected totals below locally against the CSV and manifest. The BigQuery run is pending.

Load, model and query

  1. Load the sales CSV with the table schema. Each row represents one order. Monetary values use NUMERIC.
  2. Use monthly partitions by order date and cluster by category and region. The query filters the period on the partition column.
  3. Calculate margin by dividing total gross profit by total revenue. Use LAG to compare revenue with the previous month.
