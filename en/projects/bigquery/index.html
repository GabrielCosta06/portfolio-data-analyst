Load, model and query

  1. Load the sales CSV with the typed schema. Each row represents one order and monetary amounts use NUMERIC.
  2. Partition by order month and cluster by category and region. Filter directly on the order date column.
  3. Measure margin as total gross profit divided by total revenue. LAG compares adjacent monthly aggregates. The first month has no prior period.
