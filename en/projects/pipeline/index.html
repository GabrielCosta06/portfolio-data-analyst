Run locally

git clone https://github.com/GabrielCosta06/portfolio-data-analyst.git
cd portfolio-data-analyst
python src/pipeline.py --generate
python -m unittest discover -s tests -v

Python 3.10+. The local run generates a SQLite warehouse, CSV exports, a manifest and browser data. A schema mismatch stops the run before it replaces the previous result.

The original run reloads the full synthetic dataset. To reproduce the incremental demo, install PySpark and Delta Lake as described in the run guide and use python src/incremental_lakehouse.py --verify-delta --check.
