Independent checks

SQL queries check uniqueness, positive values and whether profit equals revenue minus cost. Tests cover idempotent reruns, preservation of prior results after a schema change, and handling of empty datasets.

Count distinct rejected rows separately from rule violations, because a single row can violate several rules. Each rejected row in this fixture triggers one rule.

Checks beyond this study

A value that passes validation can still be incorrect. ERP reconciliation, extract completeness, source freshness and referential integrity with external master data require additional sources and criteria.
